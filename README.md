## Task Summaries

### Task 1: File Handling & Automation
- Read and write text and CSV files
- Automate file operations such as rename, move, and delete
- Implement error handling using try-except blocks
- Generate backup files with timestamps

### Task 2: API Integration & JSON Handling
- Fetch data using the requests library
- Parse and process JSON responses
- Apply filtering and search operations
- Handle API errors and exceptions

### Task 3: Data Analysis using Pandas
- Load and inspect datasets
- Handle missing and duplicate data
- Perform filtering, grouping, and aggregation
- Generate basic insights from data
